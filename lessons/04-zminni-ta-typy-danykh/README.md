## Підсумковий тест модуля 4

Спершу виконайте все самостійно і лише потім розгортайте відповіді. Якщо помилилися, поверніться до уроку, вказаного в дужках.

### Питання

**1.** Колега написав `$porig = (Get-Date).AddMonths(-6)`, а наступного дня у новому вікні PowerShell його фільтр `Where-Object { $_.LastWriteTime -lt $porig }` нічого не знаходить. Чому? *(урок 13)*

**2.** Що буде у змінній `$taryf` після `$taryf = 7,96` і як записати правильно? *(урок 14)*

**3.** Ви ввели `[datetime]"03.04.2026"`, а отримали 4 березня. Чому і як задати 3 квітня? *(урок 14)*

**4.** Що виведуть ці дві команди, якщо `$imya = "Олена"`? *(урок 15)*

```powershell
'Привіт, $imya!'
"Привіт, $imya!"
```

**5.** Чому `$papky[1]` повертає другу папку зі списку, а не першу? *(урок 16)*

<details>
<summary>Відповіді на питання</summary>

1. Змінні зникають після закриття вікна. У новому вікні `$porig` не існує, тобто дорівнює `$null`, і умова «дата раніша за нічого» не виконується для жодного файлу. Змінну треба створити знову.
2. Список з двох чисел: `7` і `96`. Дробові числа в командах пишуть з крапкою: `$taryf = 7.96`.
3. `[datetime]"..."` читає дату в порядку місяць.день.рік. Правильно: `Get-Date -Date "03.04.2026"` (за налаштуваннями української Windows) або `[datetime]"2026-04-03"`.
4. Перша — `Привіт, $imya!` (в одинарних лапках змінна не підставляється), друга — `Привіт, Олена!`.
5. Нумерація елементів масиву починається з нуля: перший елемент — `$papky[0]`.

</details>

### Практичні завдання

**Завдання 1.** Збережіть у змінну `$pdf` усі PDF-файли з «Завантажень», а потім окремими командами виведіть їх кількість і загальний розмір у МБ, округлений до цілого. *(уроки 13 і 14)*

<details>
<summary>Розв’язок</summary>

```powershell
$pdf = Get-ChildItem "$HOME\Downloads" -Filter *.pdf
$pdf.Count
[math]::Round(($pdf | Measure-Object Length -Sum).Sum / 1MB)
```

</details>

**Завдання 2.** Інтернет-провайдер списує 250 грн щомісяця, а на рахунку зараз 1 130 грн. Порахуйте, на скільки **повних** місяців вистачить коштів, і виведіть дату, до якої приблизно буде оплачено інтернет (сьогодні плюс стільки місяців) у форматі `dd.MM.yyyy`. *(уроки 14 і 15)*

<details>
<summary>Розв’язок</summary>

```powershell
$misyatsiv = [math]::Floor(1130 / 250)
$misyatsiv
"{0:dd.MM.yyyy}" -f (Get-Date).AddMonths($misyatsiv)
```

`[math]::Floor` округлює вниз: 4,52 місяця — це 4 повні, на п’ятий грошей уже не вистачить.

</details>

**Завдання 3.** Виведіть рядок `Звіт_2026-11-25.txt` з сьогоднішньою датою, а потім створіть у папці `PS-Kurs` порожній файл з такою назвою. *(урок 15)*

<details>
<summary>Розв’язок</summary>

```powershell
$nazva = "Звіт_{0:yyyy-MM-dd}.txt" -f (Get-Date)
$nazva
New-Item -ItemType File -Path "$HOME\PS-Kurs\$nazva"
```

</details>

**Завдання 4.** У папці `$HOME\PS-Kurs\Фото` (з уроку 15) замініть у назвах усіх `.jpg` пробіли на підкреслення. Щоб було що перейменовувати, спершу створіть файл `Фото з моря 1.jpg`. Перевірте з `-WhatIf`. *(урок 15)*

<details>
<summary>Розв’язок</summary>

```powershell
New-Item -ItemType File -Path "$HOME\PS-Kurs\Фото\Фото з моря 1.jpg"
Get-ChildItem "$HOME\PS-Kurs\Фото" -Filter "* *.jpg" |
    Rename-Item -NewName { $_.Name.Replace(" ", "_") } -WhatIf
```

Фільтр `"* *.jpg"` (з пробілом посередині) відбирає лише файли, у назві яких є пробіл. Без нього `Rename-Item` спробує «перейменувати» й решту файлів на ту саму назву і повідомить про помилку.

</details>

**Завдання 5.** Створіть список з трьох розширень (`.jpg`, `.png`, `.mp4`) і за його допомогою порахуйте, скільки таких файлів у папці «Зображення» разом із вкладеними. Результат оформіть як `[PSCustomObject]` з властивостями `Типи` (розширення через кому одним рядком) і `Файлів`. *(уроки 15 і 16)*

<details>
<summary>Розв’язок</summary>

```powershell
$typy = ".jpg", ".png", ".mp4"
$media = Get-ChildItem "$HOME\Pictures" -File -Recurse | Where-Object { $_.Extension -in $typy }
[PSCustomObject]@{
    Типи   = $typy -join ", "
    Файлів = $media.Count
}
```

</details>
