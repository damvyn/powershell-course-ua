# Урок 15. Рядки

⏱ ~30 хв · Рівень: початковий · Потрібно: [урок 14](14-chysla-daty-tak-ni.md), папка `PS-Kurs`

## Що ви вмітимете після уроку

- складати текст зі змінних і властивостей об’єктів;
- розуміти різницю між подвійними `"..."` та одинарними `'...'` лапками;
- форматувати дати й числа в тексті;
- замінювати, розділяти й склеювати текст (`-replace`, `-split`, `-join`);
- перейменовувати багато файлів однією командою.

## Ситуація з життя

Після поїздки в Карпати телефон зберіг фото з назвами на кшталт `IMG_20260712_183455.jpg`. Через рік серед сотень таких файлів не знайдеш, де Карпати, а де море. Хочеться перейменувати всі фото поїздки на `Карпати_20260712_183455.jpg` і поруч створити текстовий опис з датою й кількістю фото. Усе це — робота з **рядками**, тобто з текстом.

## Пояснення (~15 хв)

**Підготовка.** Створіть навчальну папку з «фото» (порожні файли з назвами, як у телефоні):

```powershell
New-Item -ItemType Directory -Path "$HOME\PS-Kurs\Фото"
Set-Location "$HOME\PS-Kurs\Фото"
New-Item -ItemType File -Name "IMG_20260712_183455.jpg"
New-Item -ItemType File -Name "IMG_20260712_190210.jpg"
New-Item -ItemType File -Name "IMG_20260713_091544.jpg"
```

### 1. Подвійні й одинарні лапки

Текст (рядок) береться в лапки. У PowerShell лапки бувають двох видів, і різниця між ними важлива:

```powershell
$poizdka = "Карпати"
"Фото з поїздки: $poizdka"
'Фото з поїздки: $poizdka'
```

```text
Фото з поїздки: Карпати
Фото з поїздки: $poizdka
```

- У **подвійних** лапках `"..."` PowerShell підставляє значення змінних.
- В **одинарних** лапках `'...'` текст береться буквально, як є.

> [!TIP]
> Просте правило: пишіть подвійні лапки, коли в тексті є змінна, і одинарні, коли змінних немає або знак `$` має залишитися як є.

### 2. Властивості в тексті: `$( )`

Збережемо файли у змінну і складемо опис:

```powershell
$foto = Get-ChildItem "$HOME\PS-Kurs\Фото" -Filter *.jpg
"У поїздці $poizdka зроблено $($foto.Count) фото"
```

```text
У поїздці Карпати зроблено 3 фото
```

> [!IMPORTANT]
> Просту змінну можна писати в тексті як є: `$poizdka`. Але якщо потрібна **властивість** (`$foto.Count`) або результат команди, загорніть їх у `$( )`. Без цього PowerShell підставить лише `$foto`, а `.Count` залишить звичайним текстом (див. «Типові помилки»).

### 3. Дати й числа у потрібному вигляді: `-f`

Оператор `-f` (format) підставляє значення у шаблон. Місця для значень позначають `{0}`, `{1}`… за порядком:

```powershell
"{0}: {1} фото" -f $poizdka, $foto.Count
```

```text
Карпати: 3 фото
```

Після двокрапки в `{ }` можна вказати, **як** показати значення:

| Шаблон | Значення | Результат |
|---|---|---|
| `"{0:yyyy-MM-dd}" -f (Get-Date)` | дата | `2026-11-25` |
| `"{0:dd.MM.yyyy HH:mm}" -f (Get-Date)` | дата й час | `25.11.2026 21:40` |
| `"{0:N2}" -f 1234.567` | число | `1 234,57` (2 знаки, з розділенням тисяч) |
| `"{0:N0}" -f 1234.567` | число | `1 235` (без дробової частини) |

Дату в тексті так само форматує `Get-Date -Format`:

```powershell
Get-Date -Format "yyyy-MM-dd"
```

```text
2026-11-25
```

> [!TIP]
> У шаблоні дати `MM` — це місяць, а `mm` — хвилини. Великі й малі літери тут мають значення: `yyyy-MM-dd` дає дату, а `yyyy-mm-dd` — рік, хвилини і день.

### 4. Заміна, розділення, склеювання

**Заміна** — оператор `-replace`:

```powershell
"IMG_20260712_183455.jpg" -replace "IMG_", "Карпати_"
```

```text
Карпати_20260712_183455.jpg
```

> [!WARNING]
> `-replace` сприймає перше значення як **шаблон** (регулярний вираз), у якому деякі знаки мають особливе значення. Найпідступніша — крапка: вона означає «будь-який символ». Для заміни крапки, дужок чи інших знаків пунктуації використовуйте метод `.Replace()`, який шукає текст буквально (див. «Типові помилки»).

**Розділення** — оператор `-split` ділить текст на частини за вказаним символом:

```powershell
"IMG_20260712_183455.jpg" -split "_"
```

```text
IMG
20260712
183455.jpg
```

Частини нумеруються з нуля (докладніше — в уроці 16), тож дата — це частина `[1]`:

```powershell
("IMG_20260712_183455.jpg" -split "_")[1]
```

```text
20260712
```

**Склеювання** — оператор `-join` з’єднує частини через вказаний символ:

```powershell
"Карпати", "2026", "липень" -join " "
```

```text
Карпати 2026 липень
```

Корисні властивості й методи тексту (урок 9): `.Length` — кількість символів, `.ToUpper()` і `.ToLower()` — великі й малі літери, `.Trim()` — прибрати пробіли на початку й у кінці.

### 5. Перейменовуємо всі фото однією командою

Тепер головне. `Rename-Item` уміє обчислити нову назву для кожного файлу, що надходить конвеєром. Для цього в `-NewName` пишуть фігурні дужки з `$_`, як у `Where-Object`:

> [!WARNING]
> Масове перейменування скасувати непросто. Спершу завжди запускайте команду з `-WhatIf` і перевіряйте нові назви.

```powershell
Get-ChildItem "$HOME\PS-Kurs\Фото" -Filter "IMG_*.jpg" |
    Rename-Item -NewName { $_.Name -replace "IMG_", "Карпати_" } -WhatIf
```

```text
What if: Performing the operation "Rename File" on target "Item: C:\Users\Andrii\PS-Kurs\Фото\IMG_20260712_183455.jpg Destination: C:\Users\Andrii\PS-Kurs\Фото\Карпати_20260712_183455.jpg".
...
```

Назви правильні? Запустіть без `-WhatIf` і перевірте результат: `Get-ChildItem "$HOME\PS-Kurs\Фото"`.

### 6. Багаторядковий текст: here-string

Для опису на кілька рядків є спеціальний запис: `@"` у кінці першого рядка і `"@` на **початку** останнього рядка. Змінні всередині підставляються, як у звичайних подвійних лапках:

```powershell
$opys = @"
Поїздка: $poizdka
Фото: $($foto.Count)
Опис створено: $(Get-Date -Format "dd.MM.yyyy")
"@
Set-Content -Path "$HOME\PS-Kurs\Фото\опис.txt" -Value $opys -Encoding UTF8
```

Відкрийте файл (`notepad "$HOME\PS-Kurs\Фото\опис.txt"`) і перевірте результат.

## Типові помилки

### ❌ Змінна в одинарних лапках

```powershell
Set-Content -Path "опис.txt" -Value 'Поїздка: $poizdka' -Encoding UTF8
```

У файлі: `Поїздка: $poizdka`.

**Чому:** в одинарних лапках змінні не підставляються.

### ✅ Правильно

```powershell
Set-Content -Path "опис.txt" -Value "Поїздка: $poizdka" -Encoding UTF8
```

---

### ❌ Властивість або дата в тексті без `$( )`

```powershell
$den = Get-Date
"Сьогодні $den.DayOfWeek"
```

```text
Сьогодні 11/25/2026 21:40:00.DayOfWeek
```

**Що сталося:** дві проблеми одразу. По-перше, PowerShell підставив лише `$den`, а `.DayOfWeek` залишив текстом. По-друге, дата в тексті вийшла в американському форматі (місяць/день/рік), хоча Windows українська.

**Чому:** у рядку PowerShell підставляє лише назву змінної, а дати перетворює на текст завжди однаково, незалежно від мови Windows (як `[datetime]` в уроці 14).

### ✅ Правильно

```powershell
"Сьогодні $($den.DayOfWeek)"
"Сьогодні {0:dd.MM.yyyy}" -f $den
```

---

### ❌ Крапка в `-replace`

Хочемо замінити крапки в назві `звіт.за.листопад.docx` на підкреслення:

```powershell
"звіт.за.листопад" -replace ".", "_"
```

```text
________________
```

**Чому:** у `-replace` крапка означає «будь-який символ», тому замінилися всі літери.

### ✅ Правильно

Метод `.Replace()` шукає текст буквально:

```powershell
"звіт.за.листопад".Replace(".", "_")
```

```text
звіт_за_листопад
```

---

### ❌ `.Split()` з кількома символами

```powershell
"хліб, молоко, яйця".Split(", ")
```

У Windows PowerShell 5.1:

```text
хліб

молоко

яйця
```

**Чому:** у 5.1 метод `.Split(", ")` ділить текст за **кожним** символом окремо — і за комою, і за пробілом, тому між ними з’являються порожні рядки.

> [!NOTE]
> **PowerShell 7:** той самий `.Split(", ")` ділить за всім рядком `", "` і повертає три слова без порожніх рядків. Через таку різницю в результатах краще не використовувати `.Split()` для розділення за кількома символами.

### ✅ Правильно

Оператор `-split` працює однаково в обох версіях:

```powershell
"хліб, молоко, яйця" -split ", "
```

```text
хліб
молоко
яйця
```

## Підсумок

| Що | Як |
|---|---|
| Текст зі змінною | `"Поїздка: $poizdka"` |
| Текст буквально | `'Ціна: $5'` |
| Властивість у тексті | `"$($foto.Count) фото"` |
| Шаблон | `"{0:dd.MM.yyyy} — {1}" -f $data, $tekst` |
| Дата як текст | `Get-Date -Format "yyyy-MM-dd"` |
| Замінити (шаблон) | `-replace "що", "на що"` |
| Замінити буквально | `.Replace("що", "на що")` |
| Розділити / склеїти | `-split "_"` / `-join " "` |
| Масове перейменування | `Rename-Item -NewName { ... $_ ... } -WhatIf` |
| Багаторядковий текст | `@" ... "@` |

## Перевір себе (~5 хв)

1. Що виведе `'Привіт, $env:USERNAME'`? А `"Привіт, $env:USERNAME"`?
2. Чому `"Файлів: $foto.Count"` не покаже кількість?
3. Чим `MM` відрізняється від `mm` у шаблоні дати?
4. Що поверне `"a.b.c" -replace ".", "-"` і як отримати `a-b-c`?
5. Навіщо фігурні дужки в `Rename-Item -NewName { $_.Name -replace "IMG_", "Карпати_" }`?

<details>
<summary>Відповіді</summary>

1. Перше — текст як є: `Привіт, $env:USERNAME`. Друге — з вашим ім’ям користувача: `Привіт, Andrii`.
2. Підставиться лише `$foto`, а `.Count` залишиться текстом. Потрібно `$($foto.Count)`.
3. `MM` — місяць, `mm` — хвилини.
4. `-----`, бо крапка в `-replace` означає будь-який символ. Правильно: `"a.b.c".Replace(".", "-")`.
5. Щоб нова назва обчислювалася окремо для кожного файлу з конвеєра: `$_` — поточний файл.

</details>

## Практика (~10 хв)

Виконуйте завдання в папці `$HOME\PS-Kurs\Фото`.

**Завдання 1** (легке). Виведіть рядок на кшталт `Сьогодні 25.11.2026, Wednesday` для сьогоднішньої дати, де дата у форматі `dd.MM.yyyy`, а день тижня — властивість `DayOfWeek` (вона буде англійською, це нормально).

<details>
<summary>Розв’язок</summary>

```powershell
$den = Get-Date
"Сьогодні {0:dd.MM.yyyy}, {1}" -f $den, $den.DayOfWeek
```

</details>

**Завдання 2.** Для кожного фото в папці виведіть рядок `назва — розмір КБ`, де розмір у кілобайтах з одним знаком після коми. Порожні навчальні файли покажуть `0,0 КБ`. Щоб побачити реальні розміри, виконайте ту саму команду для папки `$HOME\Pictures`.

<details>
<summary>Підказка</summary>

Використайте обчислюваний стовпець з уроку 12, а значення в `Expression` складіть шаблоном `-f`: `"{0} — {1:N1} КБ" -f $_.Name, ($_.Length / 1KB)`.

</details>

<details>
<summary>Розв’язок</summary>

```powershell
Get-ChildItem -Filter *.jpg |
    Select-Object @{ Name = "Фото"; Expression = { "{0} — {1:N1} КБ" -f $_.Name, ($_.Length / 1KB) } }
```

</details>

**Завдання 3** ⭐. Перейменуйте фото так, щоб у назві замість `20260712` була дата у форматі `2026-07-12`, наприклад `Карпати_2026-07-12_183455.jpg`. Спершу перевірте з `-WhatIf`.

<details>
<summary>Підказка</summary>

Розділіть назву за `_`: дата — це частина `[1]`. Рік — перші 4 символи (`.Substring(0, 4)`), місяць — 2 символи з п’ятого (`.Substring(4, 2)`), день — `.Substring(6, 2)`. Нумерація символів теж з нуля.

</details>

<details>
<summary>Розв’язок</summary>

```powershell
Get-ChildItem -Filter "Карпати_*.jpg" | Rename-Item -NewName {
    $chastyny = $_.Name -split "_"
    $d = $chastyny[1]
    "{0}_{1}-{2}-{3}_{4}" -f $chastyny[0], $d.Substring(0, 4), $d.Substring(4, 2), $d.Substring(6, 2), $chastyny[2]
} -WhatIf
```

У фігурних дужках може бути кілька рядків: нова назва — це те, що виводить останній рядок. Якщо ви не перейменовували фото в розділі 5, замініть фільтр на `"IMG_*.jpg"`.

</details>
