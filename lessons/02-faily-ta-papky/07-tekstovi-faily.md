# Урок 7. Текстові файли

⏱ ~30 хв · Рівень: початковий · Потрібно: [урок 6](06-stvoryuyemo-kopiyuyemo-vydalyayemo.md), папка `PS-Kurs`

## Що ви вмітимете після уроку

- записувати текст у файл і дописувати до нього нові рядки;
- читати файл повністю, лише початок або лише кінець;
- зберігати результат будь-якої команди у файл;
- шукати слово в кількох файлах одночасно;
- уникати «кракозябрів» замість українських літер.

## Ситуація з життя

Ви ведете список покупок у Блокноті, а ще в робочій папці лежать десятки текстових нотаток. Треба швидко знайти, в якій із них згадано «договір оренди». Відкривати кожну по черзі довго, а PowerShell перегляне всі файли за секунду.

## Пояснення (~15 хв)

Перед початком перейдіть у робочу папку:

```powershell
Set-Location $HOME\PS-Kurs
```

> [!IMPORTANT]
> **Головне правило цього уроку для Windows PowerShell 5.1:** коли записуєте або читаєте файл з українським текстом, додавайте параметр `-Encoding UTF8`. Чому це важливо, ви побачите в розділі 5 і в «Типових помилках». Поки що просто пишіть його в кожній команді.

### 1. Записуємо у файл: Set-Content

```powershell
Set-Content -Path "покупки.txt" -Value "хліб", "молоко", "яйця" -Encoding UTF8
```

Кожне значення через кому стає окремим рядком. Якщо файлу не було, PowerShell його створить.

> [!WARNING]
> Якщо файл **вже існує**, `Set-Content` повністю замінює його вміст. Старий текст зникає без попередження і не потрапляє до Кошика. Щоб дописати, використовуйте `Add-Content` (наступний розділ).

### 2. Дописуємо в кінець: Add-Content

```powershell
Add-Content -Path "покупки.txt" -Value "сир" -Encoding UTF8
```

Відкрийте файл у Блокноті й перевірте, що «сир» з’явився останнім рядком:

```powershell
notepad покупки.txt
```

### 3. Читаємо файл: Get-Content

```powershell
Get-Content -Path "покупки.txt" -Encoding UTF8
```

```text
хліб
молоко
яйця
сир
```

Для великих файлів (наприклад, журналів програм) зручно читати лише частину:

```powershell
Get-Content -Path "покупки.txt" -Encoding UTF8 -TotalCount 2   # перші 2 рядки
Get-Content -Path "покупки.txt" -Encoding UTF8 -Tail 2         # останні 2 рядки
```

> [!TIP]
> Короткий псевдонім `Get-Content` — `cat` або `type`, як у cmd: `type покупки.txt`. Але пам’ятайте про `-Encoding UTF8`.

### 4. Зберігаємо результат команди у файл: `>` і `>>`

Усе, що команда виводить на екран, можна «перенаправити» у файл:

```powershell
Get-ChildItem $HOME\Downloads > завантаження.txt     # створити або перезаписати
Get-ChildItem $HOME\Desktop >> завантаження.txt      # дописати в кінець
notepad завантаження.txt
```

- `>` працює як `Set-Content`: файл перезаписується;
- `>>` працює як `Add-Content`: текст дописується.

> [!NOTE]
> У Windows PowerShell 5.1 оператори `>` і `>>` записують файл у кодуванні UTF-16. Блокнот відкриває такі файли правильно, але вони вдвічі більші, а деякі програми читають їх погано. Якщо файл потрібен іншій програмі, краще використовуйте `Set-Content -Encoding UTF8`.

### 5. Що таке кодування і звідки «кракозябри»

Файл на диску — це лише числа. **Кодування** — це таблиця, за якою програма перетворює числа на літери. Якщо файл записали за однією таблицею, а прочитали за іншою, замість «Привіт» з’являється щось на кшталт `РџСЂРёРІС–С‚`.

Сучасний Блокнот зберігає файли в кодуванні **UTF-8**. А Windows PowerShell 5.1, якщо не вказати `-Encoding`, читає файл за старою таблицею Windows (для української мови це *Windows-1251*). Звідси й «кракозябри».

**Спробуйте самі:**

1. Відкрийте Блокнот: `notepad привіт.txt` і погодьтеся створити новий файл.
2. Напишіть `Привіт, світе!`, збережіть (**Ctrl + S**) і закрийте Блокнот.
3. Прочитайте файл **без** `-Encoding`:

```powershell
Get-Content привіт.txt
```

```text
РџСЂРёРІС–С‚, СЃРІС–С‚Рµ!
```

4. Тепер **з** `-Encoding UTF8`:

```powershell
Get-Content привіт.txt -Encoding UTF8
```

```text
Привіт, світе!
```

> [!NOTE]
> **PowerShell 7:** за замовчуванням використовує UTF-8 і для читання, і для запису, тому «кракозябрів» у ньому майже не буває, і `-Encoding UTF8` можна не писати. Ще одна дрібна різниця: у 5.1 `-Encoding UTF8` додає на початок файлу невидиму позначку (BOM), а в PowerShell 7 — ні.

### 6. Шукаємо текст у файлах: Select-String

```powershell
Select-String -Path "*.txt" -Pattern "молоко"
```

```text
покупки.txt:2:молоко
```

Результат показує назву файлу, номер рядка і сам рядок. Великі й малі літери за замовчуванням не розрізняються: «Молоко» теж знайдеться.

Шукати можна в усіх вкладених папках, поєднавши з уроком 4:

```powershell
Get-ChildItem -Path $HOME\Documents -Filter *.txt -Recurse | Select-String -Pattern "оренд"
```

> [!TIP]
> Символ `|` («конвеєр») передає знайдені файли наступній команді. Детально про нього — у модулі 3. Зараз достатньо знати, що так можна шукати текст у файлах з усіх підпапок.

## Типові помилки

### ❌ «Кракозябри» замість українських літер

```powershell
Get-Content нотатки.txt
```

```text
РљСѓРїРёС‚Рё РєРІРёС‚РєРё
```

**Чому:** файл збережено в UTF-8 (так робить Блокнот), а Windows PowerShell 5.1 без підказки читає його за старою таблицею Windows-1251.

### ✅ Правильно

```powershell
Get-Content нотатки.txt -Encoding UTF8
```

---

### ❌ Знаки питання замість літер у записаному файлі

```powershell
Set-Content -Path "лист.txt" -Value "Добрий день"
notepad лист.txt
```

У Блокноті: `?????? ????`

**Чому:** без `-Encoding` Windows PowerShell 5.1 записує файл за старою таблицею, яка залежить від налаштувань Windows («Мова для програм, що не підтримують Юнікод»). Якщо там вибрано англійську, українських літер у цій таблиці просто немає, і вони назавжди замінюються на `?`. На іншому комп’ютері той самий скрипт може спрацювати нормально, тому помилку легко пропустити.

### ✅ Правильно

```powershell
Set-Content -Path "лист.txt" -Value "Добрий день" -Encoding UTF8
```

---

### ❌ Хотіли дописати, а перезаписали

```powershell
Set-Content -Path "покупки.txt" -Value "банани" -Encoding UTF8
```

**Що сталося:** у файлі залишились лише «банани», весь попередній список зник.

**Чому:** `Set-Content` (і `>`) завжди замінює вміст файлу.

### ✅ Правильно

```powershell
Add-Content -Path "покупки.txt" -Value "банани" -Encoding UTF8
```

Якщо список важливий, перед експериментами зробіть копію: `Copy-Item покупки.txt покупки-резерв.txt`.

---

### ❌ Читаємо документ Word як текст

```powershell
Get-Content "$HOME\Documents\договір.docx"
```

```text
PK♥♦¶ ♠ ☺ ... [Content_Types].xml ...
```

**Чому:** `.docx`, `.xlsx`, `.pdf` — це не текстові файли, а запаковані дані в особливому форматі. `Get-Content` і `Select-String` працюють лише з простим текстом: `.txt`, `.csv`, `.log`, `.ini` тощо.

### ✅ Правильно

Документи Word відкривайте у Word (`ii "$HOME\Documents\договір.docx"`). Робота з ними з PowerShell можлива, але це вже інша, складніша тема.

## Підсумок

| Команда | Що робить |
|---|---|
| `Set-Content -Path ф -Value т -Encoding UTF8` | Записує текст (замінює вміст) |
| `Add-Content -Path ф -Value т -Encoding UTF8` | Дописує текст у кінець |
| `Get-Content -Path ф -Encoding UTF8` | Читає файл |
| `-TotalCount N` / `-Tail N` | Перші / останні N рядків |
| `команда > файл` / `команда >> файл` | Зберігає вивід (перезаписує / дописує) |
| `Select-String -Path ф -Pattern слово` | Шукає слово у файлах |
| `-Encoding UTF8` | У 5.1 потрібен для українського тексту |

## Перевір себе (~5 хв)

1. Чим `Set-Content` відрізняється від `Add-Content`?
2. Ви прочитали файл і побачили `РџСЂРёРІС–С‚`. Що треба додати до команди?
3. Яка команда покаже лише останні 10 рядків файлу `журнал.log`?
4. Що зробить `Get-Process > процеси.txt`, якщо файл `процеси.txt` вже існує?
5. Чи знайде `Select-String` слово «оплата» всередині файлу `рахунок.pdf`? Чому?

<details>
<summary>Відповіді</summary>

1. `Set-Content` замінює весь вміст файлу, `Add-Content` дописує в кінець.
2. `-Encoding UTF8`.
3. `Get-Content журнал.log -Tail 10` (з `-Encoding UTF8`, якщо там український текст).
4. Перезапише його: старий вміст зникне.
5. Ні: PDF не є простим текстовим файлом, `Select-String` працює лише з текстом.

</details>

## Практика (~10 хв)

Усі завдання виконуйте в папці `PS-Kurs` у Windows PowerShell 5.1.

**Завдання 1** (легке). Створіть файл `справи.txt` з трьома справами на завтра. Потім допишіть четверту і виведіть файл на екран.

<details>
<summary>Розв’язок</summary>

```powershell
Set-Content -Path "справи.txt" -Value "оплатити інтернет", "купити квитки", "подзвонити мамі" -Encoding UTF8
Add-Content -Path "справи.txt" -Value "забрати посилку" -Encoding UTF8
Get-Content -Path "справи.txt" -Encoding UTF8
```

</details>

**Завдання 2.** Збережіть у файл `процеси.txt` список запущених програм (`Get-Process`), відкрийте його в Блокноті, а потім виведіть у PowerShell лише перші 5 рядків файлу.

Файл створено оператором `>`, тобто в UTF-16. Подумайте, чи потрібен тут `-Encoding UTF8` під час читання.

<details>
<summary>Розв’язок</summary>

```powershell
Get-Process > процеси.txt
notepad процеси.txt
Get-Content процеси.txt -TotalCount 5
```

`-Encoding UTF8` тут не потрібен: файл у UTF-16 має на початку позначку (BOM), за якою PowerShell сам розпізнає кодування. Перші рядки — порожній рядок і заголовки таблиці.

</details>

**Завдання 3** ⭐. Вручну створіть у Блокноті два файли з кількома рядками тексту:

1. `рецепт-борщ.txt`: «буряк», «капуста», «картопля», «сметана»;
2. `рецепт-салат.txt`: «огірок», «помідор», «сметана».

Для кожного файлу: `notepad назва.txt` → погодитися створити → ввести текст (кожне слово з нового рядка) → **Ctrl + S** → закрити.

Потім однією командою знайдіть, у яких рецептах є сметана, і виведіть вміст рецепта борщу без «кракозябрів».

<details>
<summary>Розв’язок</summary>

```powershell
Select-String -Path "рецепт-*.txt" -Pattern "сметана"
Get-Content "рецепт-борщ.txt" -Encoding UTF8
```

```text
рецепт-борщ.txt:4:сметана
рецепт-салат.txt:3:сметана
```

`Select-String` за замовчуванням вважає файли без позначки BOM файлами UTF-8, тому знаходить українські слова у файлах з Блокнота без `-Encoding`.

</details>
