# PowerShell для звичайних користувачів

Безкоштовний курс українською мовою для тих, хто ніколи не працював з командним рядком. Ви навчитеся керувати файлами, отримувати інформацію про комп’ютер і автоматизувати рутинні справи за допомогою PowerShell.

- **Для кого:** звичайні користувачі Windows 10 і 11, без досвіду програмування чи адміністрування.
- **Версія:** Windows PowerShell 5.1, що вже встановлений у Windows. Відмінності PowerShell 7 позначено окремими блоками.
- **Формат:** 31 урок по ~30 хвилин (пояснення + питання + практика), після кожного модуля підсумковий тест.
- **Перевірка:** матеріал звірено з офіційною документацією [Microsoft Learn](https://learn.microsoft.com/powershell/); посилання наведено в кінці кожного уроку.

## Як навчатися

1. Проходьте уроки по черзі: кожен спирається на попередні.
2. Тримайте поруч відкрите вікно PowerShell і повторюйте кожен приклад самі. Читання без практики майже нічого не дає.
3. Спершу відповідайте на питання й розв’язуйте завдання самостійно, а вже потім розгортайте блок із відповіддю.
4. Не бійтеся червоного тексту. Помилка — це підказка, а розділ «Типові помилки» в кожному уроці пояснює, як її читати.

> [!IMPORTANT]
> Усі вправи виконуйте в навчальній папці `PS-Kurs` у своїй домашній папці (`C:\Users\<ваше ім’я>\PS-Kurs`). Ніколи не запускайте команди, яких не розумієте, від імені адміністратора.
